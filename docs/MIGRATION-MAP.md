# Mapa de evolución · Valeria

## Versión 1.0 · prototipo

- Home editorial de una página.
- Catálogo de 8 productos y 3 colecciones.
- Carrito local y checkout por WhatsApp.
- Búsqueda y fichas.
- Bilingüe ES/EN.
- Chat IA + Concierge.
- Documentación y auditoría.

## Fase 2 · producción

1. Reemplazar contacto, dominio y datos de marca.
2. Confirmar catálogo, precios, stock y políticas.
3. Integrar pasarela de pago y orden de compra.
4. Integrar CRM, newsletter y consentimiento.
5. Reemplazar imágenes por fotografía propia y optimizar.
6. Añadir focus trap, pruebas y cabeceras de seguridad.
7. Medir Lighthouse y Core Web Vitals.
8. Validar marca y textos con el cliente.

## Fase 3 · crecimiento
